# cubed

Consistent styling without getting stuck in a box!

Cubed is a CLI tool that scaffolds systematic styling with the Cube CSS methodology in mind. https://cube.fyi/

# usage

```shell
npx cubed-cli create
```

# default output

```bash
├── global
│   ├── fonts.css
│   ├── global-styles.css
│   ├── reset.css
│   ├── sizes
│   │   ├── space.css
│   │   └── text.css
│   └── theme.css
└── root.css
```
